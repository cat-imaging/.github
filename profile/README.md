# Computational Applied Tomography (CAT)

We develop algorithms and open-source software for tomographic reconstruction and inverse problems in imaging. The group is led by [Dr Ander Biguri](https://anderbiguri.github.io).

## Software

- **[TIGRE](https://github.com/CERN/TIGRE)** 🐯: GPU-accelerated toolbox for cone-beam and fan-beam CT reconstruction, in MATLAB and Python. Hosted at CERN and maintained by the CAT group.
- **[LION](https://github.com/cat-imaging/LION)** 🦁: toolbox for reliable and reproducible machine-learning tomographic reconstruction. [Documentation](https://cat-imaging.github.io/LION/)
